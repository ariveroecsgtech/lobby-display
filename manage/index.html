    Add a manager (ECSG only)
    Managers are invited from Azure, not from this app, so nobody inside a building can give access to someone else. In the Azure portal open the Static Web App "lobby-display", then Role management, then Invite: provider Microsoft Entra ID, the person's email, role manager. Or run this in Cloud Shell and send them the link it prints:
    az staticwebapp users invite -n lobby-display -g rg-lobbydisplay-demo-cus --authentication-provider AAD --user-details PERSON@EXAMPLE.COM --roles manager --domain display.ecsgapps.com --invitation-expiration-in-hours 48 --query invitationUrl -o tsv
    To remove someone: same Role management page, select the person, Delete. The app has no list of people because Azure keeps it.

    Alerts and notices

    The lobby screen supports your emergency plan; it does not replace the building's fire alarm system or a call to 911.

    What is it about
    It does not cover the screen. Nothing is published until you confirm on the next step.

    Scheduled test

    Leave "Starts at" empty to start the test right now.
    The screen is covered only during the test and comes back by itself. You can cancel it any time before or during.

    Real emergency

    Call 911 first. This puts a red alarm screen on the lobby display right away.
